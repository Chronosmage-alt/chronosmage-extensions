# Chronosmage Extensions

Custom extension index and signed APK/JAR downloads.

Add this extension store URL in Suwayomi:

```
https://raw.githubusercontent.com/Chronosmage-alt/chronosmage-extensions/main/index.pb
```

Use this store instead of Keiyoushi for these custom builds. When both stores
contain the same package, Suwayomi selects the highest version and may replace
a custom build with an upstream build. This store contains fourteen selected
extensions; additional extensions can be added to future builds.

Manga Ball, Kagane, and OniSaga include optional chapter deduplication and
preferred scanlator settings. Enable them in source settings, then refresh
the title's chapter list. AllManga also removes duplicate chapter numbers.

The index and downloads are generated automatically. Source development and
history are maintained separately. This repository contains distributable
assets, not source commits. Compiled extensions can still be inspected.
